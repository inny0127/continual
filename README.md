## 부문 선택: 미정

전제: 대학생(군휴학), 강점은 바이브코딩과 물리학 전공.

| | 부문1 빅데이터 | 부문2 비즈니스 모델 | 부문3 초소형위성 |
|---|---|---|---|
| 제출물 | 실험 결과가 있는 논문 + 표절검사 | 사업 제안서 | 아이디어 제안서 |
| 경쟁 상대 | 원격탐사 대학원 연구실 위주 (역대 대상: SAR 위상 재초점화, GEMS 오존 ML) | 학생 + 스타트업·중소기업 재직자 | 학생만 |
| 작업량 | 가장 많음: 데이터 확보·처리·실험 | 중간: 시장조사, BM, (선택) MVP | 가장 적음: 데이터 불필요 |
| 강점 연결 | 바이브코딩으로 분석 파이프라인, 재현성 15점 | 바이브코딩으로 MVP 데모 | 물리로 궤도·센서·전력·링크버짓, 바이브코딩으로 임무 시뮬레이터 |
| 외부 의존 | 아리랑 데이터 보안서약, 표절검사 도구 | 시장 데이터 | 없음 |

**추천: 부문3.**

- 학생 전용이라 경쟁이 가장 약하다.
- 데이터 없이 바로 시작할 수 있어 짧은 시간에도 진행된다.
- 대부분의 아이디어 제안서는 글뿐이다. 궤도·커버리지·링크버짓 시뮬레이션을 붙이면 타당성 20 · 실현가능성 25 · 구체성 10, 합계 55점을 숫자로 입증할 수 있다.
- 승부처는 **기여도(25)**다. 한국에 실제로 있는 문제를 골라야 한다.

2건까지 낼 수 있지만, 25일이면 1건에 집중하는 쪽이 기대값이 높다.

## 실격·감점 사유

- **이미 공개된 아이디어**는 수상 취소와 상금 환수 대상이다. 제출 전에는 public 리포, 블로그, SNS에 올리지 않는다.
- **허위 기재**가 드러나면 선정에서 제외되고 이의 제기도 할 수 없다.
- **AI 사용을 숨기면** 지침 위반이다. 사용 내역을 반드시 명시한다.
- **아리랑 데이터는 보안서약 대상**이다. `data/`에만 두고 절대 커밋하지 않는다(gitignore 처리됨).
- 다른 대회에서 **같은 아이디어로 수상한 적이 있으면** 참가할 수 없다.
